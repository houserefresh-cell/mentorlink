# תוכנית בדיקה ידנית להתראות Web Push באייפון

1. השתמשו באייפון עם iOS 16.4 ומעלה.
2. פתחו את כתובת ה־Preview או Production המאובטחת ב־HTTPS.
3. הוסיפו את MentorLink למסך הבית דרך שיתוף → הוספה למסך הבית.
4. הפעילו את MentorLink מהאייקון במסך הבית.
5. התחברו כחונך.
6. פתחו „התראות בטלפון”.
7. לחצו „הפעלת התראות”.
8. אשרו את בקשת ההרשאה של iOS.
9. לחצו „שליחת התראת ניסיון”.
10. נעלו את הטלפון ואמתו שההתראה מופיעה.
11. לחצו עליה ואמתו שנפתח עמוד MentorLink המתאים.
12. שלחו פנייה כללית מחשבון הורה ואמתו שמתקבלת התראת פנייה נפרדת.
13. שלחו בקשת פגישה ואמתו שמתקבלת התראת בקשת פגישה נפרדת.

מינוי ב־Preview ומינוי ב־Production עשויים לדרוש הפעלה נפרדת משום שמדובר במקורות אתר שונים.
